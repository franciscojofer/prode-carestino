## Mandatory Code Commenting Standard

All code comments MUST be written in English.

Required documentation rules:

1. File Header
Every script must begin with a short comment block describing:
- the purpose of the file
- the main functionality
- the role of the script within the project

2. Functions
Every function must include a short descriptive comment above it explaining:
- what the function does
- key inputs
- expected output or side effects

3. Variables
Every non-trivial variable declaration must include a short descriptive comment explaining:
- what the variable represents
- why it exists when not obvious

Comment style requirements:
- Keep comments concise and technical
- Do not add meaningless comments for obvious code
- Optimize comments for readability by non-programmers
